# mlvm-readelf

ELF32/64 relocatable identity, content sections, symbols, REL/RELA and groups in
either byte order through the shared Limestone adapter. Select views with
`--file-header`, `-S`, `-s`, `-r`, `--groups`, or `-a` (default). ELF archives are
also accepted. `-h` is help; program headers/dynamic metadata and GNU readelf
output compatibility are outside this command's current contract.

See [TOOLS.md](../../docs/TOOLS.md) for exact options and build availability.
